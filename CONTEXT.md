# Portal

Одностраничные HTML-отчёты (портал), открывающиеся с главной страницы с авторизационным токеном. Контекст здесь — словарь схемы организационной структуры.

## Language

### Схема оргструктуры

**Узел**:
Прямоугольный блок на схеме: подразделение или роль. Имеет рамку (границу прямоугольника).
_Avoid_: блок, вершина

**Связь**:
Линия между двумя узлами, отображающая отношение (подчинение, коммуникация и т.п.). Направлена от источника к приёмнику.
_Avoid_: линия, ребро, edge

**Тип связи**:
Семантика отношения: `sub` (подчинение), `plan` (перспектива подчинения), `comm` (коммуникации), `key` (ключевая связка), `ops` (оперативное управление), `future` (будущая структура). Тип определяет стиль линии.

**Рамка узла**:
Граница прямоугольника узла; сторона обозначается первой буквой: T (верх), B (низ), L (лево), R (право).

**Точка привязки**:
Точка на рамке узла, в которой начинается (`s_pt`) или заканчивается (`t_pt`) связь. Формат: буква стороны + процент длины этой стороны (0–100); для T/B процент отсчитывается по X слева направо, для L/R — по Y сверху вниз. Пустое значение означает автоматический расчёт конца.
_Avoid_: якорь, anchor
